This folder contains the output graphic plots (jpeg files_ for the powershell scripts CTD#_Hex_Plot.bat, CTD#_Hex_Plot_Field.bat, CTD#_CNV_Create.bat

The Hex file plots are helpful for quickly plotting the RAW hex files while out in the field to ensure that the CTD is collecting good data.

The CNV create also generates plots of each hydrographic cast.  Both outputs are used for visual QC.
