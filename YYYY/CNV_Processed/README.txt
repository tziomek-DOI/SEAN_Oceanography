This folder will contain the output CNV files that are generated from running the Powershell script that processes raw Hex files into CNV files.  The script (CTD#_CNV_Create.bat) executes many processing steps using the software version SBEDataProcessing-win. Tese processing steps are discussed in the protocol. 

The folder also needs a temp folder to house intermediate products in the data processing routine.

Learn more by reading the OC_C Protocol.
