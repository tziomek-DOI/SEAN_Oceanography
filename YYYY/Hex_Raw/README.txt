This folder is where all the raw HEX files are downloaded for each cruise during the given year. Hex files follow this file naming convention:

YYMM_CTD#_DUMP#_CAST_STATION#

YYMM = Two digit cruise year and month

CTD# = One digit CTD# (7 for 2026, 8 for 2027 alternating forward in time)

CAST# = Three digit sequential cast.  First cast of the season will be 001. Second cast = 002 and so on) 

STATION# = Two digit station code name ( 00, 01, 24, 02, 03, 04, 05, 06, 07, 08, 09, 10, 11, 12, 13, 14, 16, 17, 18, 19, 20, 21 )

Read the OC_B for more information.
